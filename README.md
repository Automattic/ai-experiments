# Automattic AI Experiments

Welcome to Automattic's **AI Experiments** monorepo—a public repository where we share prototypes, demos, and proof-of-concept projects that explore how AI can enhance the WordPress and WooCommerce ecosystems.

## Overview

This repository serves as a public showcase where Automattic developers share experimental AI projects with the broader WordPress community. It's a space for open collaboration, learning, and gathering feedback. Projects here are experimental by nature — *there's no expectation of production-level stability or ongoing maintenance*.

## What You'll Find

- **Model Context Protocol (MCP) Servers**: Located in the `/mcp` directory, these servers enable AI assistants to interact with Automattic services through natural language:
  - **WooCommerce MCP Server**: A full-featured server for AI-powered WooCommerce store management
  - **WordPress.com MCP Server**: (In Development) For interacting with WordPress.com services
- **AI-Enabled Plugins**: WordPress plugins that leverage AI services or machine learning libraries
- **Integration Prototypes**: Early ideations around AI features related to WooCommerce, WordPress.com, or other Automattic platforms

Each subfolder contains its own experiment with a brief README explaining what it does, why it exists, and how to try it out.

## Contributing

This repository is maintained by Automattic developers, but we welcome engagement from the entire WordPress community! Whether you want to try out experiments, provide feedback, or suggest improvements, here's how you can participate:

1. **Fork and Clone** this repo to explore and experiment with the code.  
2. **Open Issues** to report bugs, suggest improvements, or start discussions.  
3. **Submit Pull Requests** if you have ideas for enhancing existing experiments.
4. **Share Feedback** on what you'd like to see or how these experiments could be more useful.

Automattic developers can also directly contribute new experiments following internal guidelines.
